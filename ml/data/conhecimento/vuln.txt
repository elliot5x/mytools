Contexto Avançado

1. Vetor SMB (Portas 139 e 445):
   - A presença do Samba (smbd 3.X - 4.X).
   - Ações: Faça enumeração de compartilhamentos anônimos (Null Session).
   - Comandos úteis: `smbclient -L //IP_DO_ALVO/ -N` ou `enum4linux -a IP_DO_ALVO`.
   - O que buscar: Compartilhamentos acessíveis sem senha (ex: "anonymous") que costumam guardar logs, arquivos de texto, ou listas de palavras (wordlists) customizadas.

2. Vetor Web/Email (Porta 80 - SquirrelMail):
   - O SquirrelMail exposto na porta 80 é a porta da frente para usar o que você achar no SMB.
   - Como é um webmail clássico, a lógica é: pegar a wordlist/credenciais no SMB e testar no login do SquirrelMail (via Burp Suite, Hydra, etc.).
   - Entrar no webmail costuma revelar o próximo passo da máquina (dicas de diretórios escondidos, novas senhas, etc).

3. POP3/IMAP (Portas 110 e 143 - Dovecot):
   - Estão abertas para dar suporte ao webmail. O SquirrelMail é só a interface web para esses serviços. Raramente você ataca eles direto aqui, o foco é o login web.

4. Resumo do Fluxo Lógico:
   Enumere o SMB -> Colete possíveis usuários e senhas (arquivos ocultos) -> Faça login no SquirrelMail -> Leia os e-mails para avançar.
