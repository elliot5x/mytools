# Categorias de vulnerabilidade, protocolos comuns e CVEs de exemplo

Referência rápida cruzando classes de vulnerabilidade com os protocolos onde
costumam aparecer e uma CVE famosa de exemplo — usado como contexto pela base
de conhecimento (ml/conhecimento.py) para enriquecer o relatório gerado por
ml/relatorio_ia.py.

## Injection (SQLi, RCE, Command Injection)

O sistema aceita comandos maliciosos misturados com dados de entrada, e o
atacante consegue fazer o backend interpretar parte dos dados como código ou
comando.

- Protocolos comuns: HTTP/HTTPS, LDAP, SQL (TCP/3306, TCP/1433)
- CVE-2021-44228 (Log4Shell): injeção via HTTP que forçava conexões LDAP
  maliciosas, resultando em execução remota de código.
- CVE-2023-34362 (MOVEit): SQL Injection no banco de dados da aplicação,
  permitindo acesso não autorizado aos dados.

## Falhas Criptográficas

Exposição de dados sensíveis por criptografia fraca, mal implementada, ou
ausente onde deveria existir.

- Protocolos comuns: SSL/TLS, HTTPS, FTP
- CVE-2014-0160 (Heartbleed): falha no protocolo TLS (biblioteca OpenSSL)
  que permitia ler memória arbitrária do servidor, incluindo chaves privadas
  e credenciais.

## SSRF (Server-Side Request Forgery)

O atacante força o servidor a fazer requisições para locais internos ou
restritos que ele não teria acesso direto de fora.

- Protocolos comuns: HTTP/HTTPS, DNS, SMB
- CVE-2021-26855 (ProxyLogon): falha no Microsoft Exchange explorada via
  requisições HTTP forjadas, permitindo acesso a caixas de e-mail internas.

## Quebra de Controle de Acesso

Usuários conseguem acessar páginas, funcionalidades ou dados que deveriam
estar restritos a outros perfis (ex.: usuário comum acessando função de
administrador).

- Protocolos comuns: HTTP/HTTPS (headers, cookies, sessões)
- CVE-2018-7600 (Drupalgeddon2): execução remota de código via bypass no
  controle de acesso do Drupal.

## Cross-Site Scripting (XSS)

Injeção de scripts maliciosos que rodam no navegador de outros usuários que
visitam a página afetada, podendo roubar sessão, credenciais ou redirecionar
o usuário.

- Protocolos comuns: HTTP/HTTPS (JavaScript executado no DOM)
- CVE-2021-24284: exemplo clássico de XSS armazenado em plugin do WordPress.

## Componentes Desatualizados / Inseguros

Uso de bibliotecas, frameworks ou plugins de terceiros com falhas de
segurança já conhecidas e corrigidas em versões mais novas, mas que não
foram atualizadas no alvo.

- Protocolos comuns: HTTP, SMTP, SSH, TCP/IP em geral (qualquer serviço que
  dependa de uma biblioteca vulnerável)
- CVE-2017-5638 (Apache Struts): a falha explorada no vazamento de dados da
  Equifax, via biblioteca desatualizada exposta em endpoint HTTP.
